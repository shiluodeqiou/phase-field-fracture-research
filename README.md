# 相场断裂文献与程序研究资料

这是一个用于学习和研究相场断裂（phase-field fracture）的资料库，包含文献、阅读笔记、术语库以及相关数值程序。

## 目录

- \参考文献/\
  - \pdf/\：主要参考文献
  - \markdown/\：文献解析和学习笔记
  - \相场文献阅读进展与问题记录.docx\：阅读进度与问题记录
- \相场程序/\
  - \程序目录1-相场模型+氢致裂纹/\：氢致开裂相场模型及相关 Abaqus 文件
  - \程序目录2-相场模型+机器学习/\：结合机器学习的相场断裂程序压缩包
  - \程序目录3-相场模型/\：GRIPHFiTH 相关程序压缩包
- \术语库_phase-field-fracture.csv\：相场断裂术语库
- \zcode_work/\：文献阅读过程中的渲染结果、图像和辅助脚本

## 主题

资料主要涉及：

- 脆性断裂和韧性断裂的相场建模
- 氢致开裂的相场模型
- 热力学一致的多场有限元实现
- 物理信息深度学习与相场断裂
- 变分原理、Gamma 收敛和交替最小化
