# zcode_work

本目录存放 ZCode 在阅读记录整理过程中生成的脚本和临时文件，避免污染项目主目录。

- `scripts/`：生成、更新、校验、导出 docx 的 Python / PowerShell / VBScript 脚本。
- `paper1/paper1_text.txt`：从 2000 年 Bourdin–Francfort–Marigo 论文 PDF 抽取的文本。
- `paper1/pages/`：论文页面渲染图和局部裁剪图。
- `rendered/reading_log/`：阅读记录 docx 导出的 PDF 及页面 PNG。

正式交付物仍在：

- `../参考文献/相场文献阅读进展与问题记录.docx`

原始文献仍在：

- `../参考文献/pdf/`
- `../参考文献/markdown/`
